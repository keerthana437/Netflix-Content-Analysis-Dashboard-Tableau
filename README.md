# 🎬 Netflix Content Analysis Dashboard | Tableau

## Project Overview
An interactive Tableau dashboard designed to analyze Netflix movies and TV shows, identify content trends, and present meaningful insights using a professional black-and-red theme.

## Dataset
- **Total Titles:** 8,807
- **Movies:** 6,131
- **TV Shows:** 2,676

## Tools Used
- Tableau
- Microsoft Excel
- CSV Dataset
- Data Visualization

## Key Features
- Movie and TV show analysis
- Year-wise content growth
- Country-wise content distribution
- Popular genres and audience ratings
- Movie duration and TV show season analysis
- Interactive filters and KPI cards

## Key Insights
- Movies represent 69.6% of the catalogue.
- TV shows represent 30.4%.
- Content additions peaked in 2019, with 2,016 titles.

## 🎨 Dashboard Design
Professional black-and-red colour theme inspired by Netflix branding.
